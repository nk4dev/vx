Web3用語集（日本語）

VX SDKやブロックチェーン開発でよく使う基本用語をまとめています。

ウォレット（Wallet）

暗号資産を管理し、トランザクションに署名するためのアプリや仕組みです。秘密鍵を保持し、送金やdApp接続に使います。

公開鍵 / 秘密鍵（Public Key / Private Key）

公開鍵はアドレス生成に使われ、秘密鍵は所有権の証明と署名に使われます。秘密鍵は絶対に他人へ共有してはいけません。

ガス（Gas）

ブロックチェーン上で処理を実行するための手数料の概念です。複雑な処理ほど多くのガスを消費します。

トランザクション（Transaction）

送金やコントラクト呼び出しなど、チェーン上へ記録される操作単位です。承認後にブロックへ取り込まれます。

スマートコントラクト（Smart Contract）

ブロックチェーン上で自動実行されるプログラムです。条件に応じて状態更新やトークン移転を行います。

RPC（Remote Procedure Call）

ノードへアクセスするための通信インターフェースです。残高照会、ブロック取得、送信処理などを行います。

NFT（Non-Fungible Token）

一意性を持つトークンです。アート、会員証、ゲームアイテムなど、個別識別が必要な資産に利用されます。

dApp（Decentralized Application）

分散型アプリケーションのことです。フロントエンドとスマートコントラクトを組み合わせて動作します。

シードフレーズ（Seed Phrase）

ウォレット復元に使う単語列です。秘密鍵のバックアップに相当するため、オフラインで厳重管理が必要です。
